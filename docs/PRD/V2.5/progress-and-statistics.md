# V2.5 模块 PRD：进度与统计

| 文档属性 | 内容 |
| --- | --- |
| 所属版本 | v2.5.0 |
| 模块状态 | 已确认 v1.0 |
| 依赖基线 | PRD v2.1 FR-16 与现有前端统计页设计 |
| 模块目标 | 保留现有视觉方案，去除硬编码和 Mock，让用户理解真实学习进展 |

---

## 1. 模块边界

进度与统计作为独立模块验收。本模块负责首页进度摘要、统计页指标、时间口径、空数据和数据刷新；
不负责制定学习计划或修改 FSRS 排程。

### 1.1 本期包含

- 现有统计页视觉结构的真实数据接入；
- 首页今日目标和进度摘要；
- 当前自然周活动、周对比和目标完成；
- 回忆表现、连续学习、已掌握卡片；
- 项目与牌组进度；
- 跨设备一致的统计结果；
- 学习时长与来源切片（服务端会话聚合，跨设备一致）；
- 加载、空数据、失败和更新时间状态。

### 1.2 本期不包含

- 社交排名、好友对比或公开分享；
- AI 学习诊断、预测分数或自动建议；
- 用户自定义报表、导出或多维筛选器；
- 多项目横向比较；
- 以 Mock 数据填补没有发生的学习行为。

---

## 2. 数据范围

- 首页“今日目标”只针对当前学习项目；
- 项目详情展示该项目的卡片、到期、已学习和掌握进度；
- 牌组详情展示该牌组的对应进度；
- 独立统计页默认展示当前账号全部真实学习活动，不提供项目筛选；
- “今天”、自然周和连续学习天数统一使用账号级 IANA 学习时区；设备本地时区只用于首次建议，不能分别分桶；
- 自由刷题不进入学习活动和评级统计；
- 已删除的卡片、牌组或项目按其删除语义退出当前统计，不保留可见的幽灵计数。

---

## 3. 功能需求

### V25-STATS-FR-01 现有设计真实化

- 沿用当前前端统计页已完成的视觉层级和主要卡片布局；
- 所有数字、百分比、柱状图、趋势和进度均来自当前账号真实数据；
- 删除或替换固定数组、固定日期、固定百分比和随机演示值；
- 当后端没有对应真实指标时，该组件隐藏或展示明确空态，不使用 `0` 冒充真实结果；
- 前端文案和图形不得把“复习次数”误写成“卡片数量”或反之。

### V25-STATS-FR-02 今日学习计划

- 展示今日已完成的去重卡片数、实际核心队列目标和完成比例（V25-D-39：计划为账号级，不再展示"当前学习项目"）；
- 账号级计划分别保存每日新学目标和每日巩固目标，首页合计目标为当天实际可用队列数量；
- 同一张卡当天多次评级只计一次今日完成；
- 自由刷题不计入；
- 未配置计划时不显示伪目标，改为计划设置入口；
- 任一目标当日变化后，完成比例按最新服务端计划计算，已完成值不回退。

### V25-STATS-FR-03 周活动与目标

统计页继续使用周一作为自然周起点，并根据账号设置的 IANA 学习时区分桶：

| 指标 | V2.5 口径 |
| --- | --- |
| 周活动 | 本周每天成功记录的学习评级数量，以及本周总评级数量。 |
| 周变化率 | 与上周总评级数量比较；上周为 0 时展示“暂无对比”，不得显示虚假 0%。 |
| 周目标 | 账号偏好 `daily_learning_goal` × 7（V25-D-39：项目级周目标随项目级计划退役）。 |
| 周目标完成率 | 本周不同 `(学习日期, card_id)` 的数量 / 周目标，上限显示 100%；无有效目标时展示空态。 |

“周活动”用于反映练习投入，“周目标完成率”用于反映计划完成，两者分子不同，界面必须避免混淆。

- 同一卡片在同一学习日期评级多次，周目标分子只计 1；同一卡片在不同学习日期完成，各日期分别计 1；
- 周目标使用当前有效的双目标之和 × 7；用户在周中修改任一目标后，本周分母立即按新值重算，历史评级不改写；
- 学习时区改变后，页面按新时区重新计算当前统计区间，但原始事件时间戳不变；界面应更新时间和分桶结果，
  不保存两套互相矛盾的客户端周统计。

### V25-STATS-FR-04 学习表现

继续提供历史 PRD 已定义的真实指标：

- 回忆正确率；
- 首次答对率；
- 记忆保持率；
- 连续学习天数；
- 已掌握卡片数。

评级中 `GOOD` 继续作为正确口径，掌握判定继续继承当前 FSRS 成熟卡口径。比率分母为 0 时显示“暂无数据”，
不显示 0%。V2.5 不把这些指标包装为考试成绩或知识能力评价。

### V25-STATS-FR-05 项目与牌组进度

项目和牌组至少提供：

- 卡片总数；
- 未开始、初学中、需重学、巩固中、已掌握数量；
- 当前到期数量；
- 评分次数与最后学习时间；掌握比例由已掌握数 / 总数派生。

项目汇总不得重复计算同一张卡；生成失败且未发布的卡片不计入任何进度。

### V25-STATS-FR-06 刷新、空态与失败

- 页面打开和重新获得前台焦点时读取最新可用数据；
- 用户完成评级后，今日目标和统计允许短暂最终一致，但必须显示数据更新时间；
- 请求失败时保留上一次成功数据并标记“暂未更新”，提供重试；
- 新账号无学习数据时展示引导创建学习项目，不显示全零的伪仪表盘；
- 跨设备查看同一账号时，已同步的评级应产生一致统计结果；
- 客户端不得以上报的任意临时时区覆盖账号学习时区；统计服务应返回用于本次计算的时区标识。

### V25-STATS-FR-07 学习时长与来源切片

- 学习时长以服务端学习会话聚合为唯一权威来源，跨设备一致；客户端本机计时长仅作离线兜底展示；
- 看板接口下发服务端聚合时长（周合计、按日分布与 PLAN/BACKLOG/ADHOC 来源拆分）；统计页**不新增独立时长卡**——项目与卡组详情页既有的「学习时长」卡直接切换为服务端会话累计（全历史、跨设备一致，V25-D-37），设备本地全量累计秒数口径随之废弃删除；
- 时长数据为尽力送达的观测数据，不与评级事实数据混同口径；
- 升级过渡期未标记来源的历史评分不计入来源拆分（未分类），不虚构归因。

## 4. 验收标准

### V25-STATS-AC-01 真实数据

- 空账号、少量真实评级和跨周数据三种场景下，页面不出现固定演示值；
- 首页、项目、牌组和统计页的相同指标口径一致；
- 生成失败的隔离卡片和自由刷题不进入统计。

### V25-STATS-AC-02 时间与目标

- 周一分桶、用户时区和跨周对比正确；
- 当前项目周目标由每日新学与每日巩固目标之和乘 7 得到；账号总体活动仍只展示全局真实活动，不以项目目标冒充账号目标；
- 同一卡片同日多次只计一次周完成，跨学习日期则分别计数；周中修改任一目标后分母立即重算；
- 多设备使用同一账号学习时区，改变设备时区不会静默改变统计；
- 上周为 0、比率无分母和无当前项目时显示约定空态。

### V25-STATS-AC-03 更新与恢复

- 学习评级成功后统计最终更新，重复事件不重复计数；
- 网络失败保留上次成功数据并提供重试，不展示伪最新状态；
- 同一账号更换设备后看到一致的已同步进度。

### V25-STATS-AC-04 学习时长与来源切片

- 同一账号多设备学习后，看板接口返回的服务端聚合时长一致；
- 重复/乱序的时长上报不叠加（绝对值合并）；
- 来源拆分与今日计划/积压巩固/卡组临时学习的实际入口一致；
- 统计页不因时长数据新增独立卡片，页面布局与升级前一致；
- 项目/卡组详情的「学习时长」卡读取服务端会话累计，多设备一致。

---

## 5. 模块完成条件

本模块只有在现有统计页全部可见指标均有真实数据来源或被合理隐藏，且首页、项目、牌组与统计页口径一致、
Mock 和硬编码已清除时，才可标记为 V2.5 进度与统计模块完成。

## 6. 学习闭环重构增量（2026-08-29）

进度不再维护重复计数器，统一由可见卡片、ReviewState 快照和不可变 ReviewEvent 聚合投影：总卡数、未开始、初学中、需重学、巩固中、已掌握、当前到期、评分次数和最后学习时间。项目进度接口按项目全部可见卡聚合（项目周统计接口已随 V25-D-39 退役）；账号看板继续保持全局活动范围。到期状态独立于阶段分布计算，缺失数据以 `—`/空态展示。
