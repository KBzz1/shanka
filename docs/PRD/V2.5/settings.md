# V2.5 模块 PRD：设置

| 文档属性 | 内容 |
| --- | --- |
| 所属版本 | v2.5.0 |
| 模块状态 | 已确认 v1.0 |
| 依赖基线 | PRD v2.1 FR-17、V2.4 账号资料与 V2.5 制卡/学习规则 |
| 模块目标 | 将影响持续使用的默认偏好集中管理，并明确本机设置与账号同步设置的边界 |

---

## 1. 模块边界

本模块负责设置页结构、账号偏好、默认制卡配置、每日学习量、学习时区、主题与 DeepSeek API Key。个人资料弹窗的
具体行为由[账号与个人主页](account-and-profile.md)负责。

### 1.1 本期包含

- 个人资料入口；
- 默认覆盖深度；
- 默认难度比例；
- 每日学习量；
- 学习时区；
- DeepSeek API Key 验证、保存和状态；
- 主题与外观；
- 本机/云端保存边界；
- Release 隐藏服务器和 Debug 设置。

### 1.2 本期不包含

- 用户修改生产服务器地址；
- 模型选择、温度、Token 上限或 Prompt 编辑；
- FSRS 参数调整；
- 数据导出、清空账号或账号注销；
- 通知、社交和付费设置；
- 自定义头像上传。

---

## 2. 设置分组

| 分组 | 设置项 | 保存位置 |
| --- | --- | --- |
| 个人资料 | 昵称、系统预设头像；个人主页展示只读邮箱 | 账号云端 |
| 制卡默认值 | 覆盖深度、三档难度比例 | 账号云端 |
| 学习计划 | 每日学习量、学习时区 | 账号云端 |
| AI 服务 | DeepSeek API Key | 服务端安全保存，客户端仅展示状态 |
| 外观 | 跟随系统、浅色、深色 | 本机 |

昵称和头像可以通过首页头像打开的个人主页弹窗修改；设置页保留“个人资料”入口并打开同一弹窗，
不得维护两套不同的资料编辑界面。

## 3. 功能需求

### V25-SET-FR-01 默认覆盖深度

- 选项为“精简／均衡／充分覆盖”；
- 默认建议使用“均衡”；
- 设置只作为新制卡任务的初始值，不修改已经创建或正在执行的任务；
- 用户仍可在单次任务中覆盖默认值；
- 选项只描述知识覆盖语义，不展示卡片数量或数量区间；
- 保存后跨设备生效。

### V25-SET-FR-02 默认难度比例

- 使用与制卡页一致的三段比例条和两个拖动点；
- 仅支持 10% 整数档，三段始终合计 100%，任一档允许为 0%；
- 默认值为基础记忆 40%、理解分析 40%、开放深问 20%；
- 设置只影响以后新建的制卡任务，不改变历史任务、样卡、牌组或现有卡片；
- 保存失败时恢复最近一次成功值并提供重试。

### V25-SET-FR-03 每日学习量

- 默认 50 张；
- 可选 10～200 张，按 10 张步长调整；
- 设置影响当前账号的每日计划并跨设备同步；
- 修改后当天未完成目标即时按新值更新，已经完成的张数不回退；
- 统计页周目标自动按每日学习量 × 7 派生，不再提供独立周目标设置。

### V25-SET-FR-04 学习时区

- 学习时区使用 IANA 时区名称，决定“今天”、周一自然周、今日目标和连续学习天数的日期边界；
- 账号第一次获得该设置时，使用当前设备时区作为建议并保存到账号；若设备无法提供有效 IANA 时区，
  必须让用户选择，不得把不明时区静默写成固定地区；
- 后续设备时区与账号学习时区不同时，App 提示用户选择“继续使用原时区”或“更新为当前设备时区”，
  未确认前保持账号原值；
- 用户可在设置页主动修改，修改成功后跨设备生效，并立即刷新今日计划、周统计和连续学习展示；
- 修改学习时区不改写历史事件时间戳和 FSRS 到期时间，只改变日期归桶和页面统计区间；
- 时区保存失败时继续使用最近一次服务端成功值，不得让不同页面各自使用设备时区。

### V25-SET-FR-05 DeepSeek API Key

- 提供输入、验证并保存入口；
- 成功保存后不再显示完整 Key，只展示脱敏标识和状态；
- 状态至少区分：可用、无效、余额不足、暂时无法验证、未设置；
- 新 Key 验证失败时不得覆盖原有可用 Key；
- API Key 不进入客户端明文持久化、普通日志、任务详情、统计或错误响应；
- 制卡需要 Key 但当前不可用时，流程保留用户配置并引导前往设置，不清空学习项目；
- V2.5 不提供模型、价格、额度估算或提示词设置。

### V25-SET-FR-06 主题与外观

- 保留跟随系统、浅色、深色三种模式；
- 主题只保存在本机，不要求跨设备同步；
- 所有正式页面、弹窗、Snackbar 和头像选择在浅色与深色模式下均可阅读；
- 主题切换不重启或清空当前任务输入。

### V25-SET-FR-07 Release 与 Debug 边界

- Release 固定连接正式后端，普通用户不能查看或修改服务器地址；
- Debug 构建可保留本机环境连接能力，但不得通过账号云端同步到 Release；
- Release 隐藏 Debug、测试平台、Mock 数据、开发者开关和未完成的设置入口；
- 不出现“后续 AI 设置”“未构建”等占位项。

### V25-SET-FR-08 保存反馈

- 设置修改成功后提供轻量成功反馈，不阻断用户；
- 网络失败时明确标记未保存，并保留可重试操作；
- 快速连续调整滑块时以用户停止后的最终值保存，避免大量重复请求；
- 同一账号多设备修改以最后一次成功保存为准，V2.5 不提供冲突合并界面。

## 4. 验收标准

### V25-SET-AC-01 云端默认值

- 覆盖深度、难度比例、每日学习量和学习时区保存后，重新启动和更换设备仍一致；
- 新制卡任务使用最新默认值，历史任务不被改变；
- 每日学习量变化正确更新今日目标和派生周目标。

### V25-SET-AC-02 学习时区

- 首次设置、设备时区相同、设备时区不同、用户主动修改和保存失败场景均按约定处理；
- 未经确认不自动改变账号时区；确认更新后各设备的今日、自然周和连续学习口径一致；
- 修改时区不改写历史事件或排程，且页面不会同时出现两种日期口径。

### V25-SET-AC-03 API Key

- 可用、无效、余额不足、暂时失败和未设置状态均有真实反馈；
- 验证失败不覆盖旧有效 Key；
- 客户端、响应、日志和任务页面不出现完整 Key。

### V25-SET-AC-04 Release 清理

- Release 中普通用户无法修改服务器地址；
- Debug/测试/占位设置全部不可见；
- 主题切换后所有 V2.5 核心页面可正常阅读和操作。

---

## 5. 模块完成条件

本模块只有在云端偏好、本机主题和 API Key 安全边界分别按要求验收，且 Release 设置页不存在 Debug、
占位或无效入口时，才可标记为 V2.5 设置模块完成。
