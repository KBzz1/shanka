# V2.5 模块 PRD：学习与复习

| 文档属性 | 内容 |
| --- | --- |
| 所属版本 | v2.5.0 |
| 模块状态 | 已确认 v1.0 |
| 依赖基线 | PRD v2.1 FR-15、FSRS 四档评级与 V2.5 学习项目语义 |
| 模块目标 | 连接制卡结果与长期复习，形成类似背单词产品的清晰每日计划 |

---

## 1. 模块边界

本模块负责当前学习项目、学习章节范围、今日目标、新卡学习、到期复习、四档评级和自由刷题。
指标口径和统计页面由[进度与统计](progress-and-statistics.md)负责。

### 1.1 本期包含

- 同一时刻一个当前学习项目；
- 新卡学习章节范围；
- 每日学习量；
- 到期卡优先、新卡补足；
- 新卡和复习卡统一四档自评；
- FSRS 后续排程；
- 自由刷题五种方式；
- 今日完成、待复习积压和空状态。

### 1.2 本期不包含

- 同时混合多个学习项目制定每日计划；
- 用户自定义 FSRS 参数或手动修改到期时间；
- 复习闯关、排行榜、社交打卡或奖励商城；
- 自由刷题中的评级、排程或统计计数；
- 自动替用户判断“真正掌握”。

---

## 2. 当前学习项目与范围

### V25-STUDY-FR-01 当前学习项目

- 同一账号同一时刻只能有一个当前学习项目；
- 用户可从已有学习项目中切换，选择后跨设备保存；
- 切换项目不删除或重置原项目的学习记录；
- 当前项目被删除后，进入“未选择当前学习项目”空态，引导用户选择其他项目或创建新项目；
- 独立牌组不进入首页每日计划，但用户仍可从牌组详情复习其中的到期卡或自由刷题；相关有效评级正常更新排程和账号统计。

### V25-STUDY-FR-02 新卡章节范围

- 用户可在当前项目中任意多选章节，作为接下来学习新卡的范围；
- 手动新增、文本导入、因删除章节而保留或其他无有效章节归属的卡片统一出现在“未归属章节”，用户可像普通章节一样
  选择或取消该分组；
- 章节范围只限制从未评级的新卡，不屏蔽已经学习且到期的卡片；
- 到期复习覆盖当前项目全部已学习卡，无论其章节是否仍在新卡范围；
- 修改范围只影响后续计划，不撤销已有评级或排程；
- 新卡按章节顺序、章节内稳定卡片顺序进入计划。

---

## 3. 每日计划

### V25-STUDY-FR-03 每日学习量

- 设置名称为“每日学习量”，不再要求用户设置周目标；
- 默认 50 张，可选 10～200 张，按 10 张步长调整；
- 设置跨设备保存；
- 周目标仅作为统计派生值，等于每日学习量 × 7，用户无需单独配置；
- 当天修改每日学习量后，尚未完成部分按新目标更新，已完成数量不回退。

### V25-STUDY-FR-04 学习日期与时区

- “今天”、自然周和连续学习天数均以账号设置的 IANA 学习时区为准，而不是各设备临时时区；
- 同一账号所有设备读取同一个学习时区，跨设备提交的评级按该时区归入同一学习日期；
- 设备时区变化不得静默改变计划边界；用户确认更新学习时区后，从确认时刻起使用新时区计算页面，
  已成功记录的事件时间戳和 FSRS 到期时间不被改写；
- 日期边界变化时，客户端以服务端返回的学习日期和计划结果为准，避免离线本地重复创建“今日计划”。

### V25-STUDY-FR-05 今日目标编排

今日计划遵循：

```text
当前项目全部到期卡
→ 按风险与逾期程度优先
→ 若未达到每日学习量，以所选章节的新卡补足
```

业务规则：

- 到期卡数量小于每日目标：全部到期卡进入计划，剩余名额由范围内新卡补足；
- 到期卡数量等于或大于每日目标：今日主计划只安排到期卡，不安排新卡；
- 到期积压超过目标时，完成主计划后仍显示“还有 N 张待复习”，用户可选择继续；
- 若没有到期卡也没有范围内新卡，展示真实完成或无可学习卡片状态；
- 同一张卡当天首次完成一次有效评级后计入今日完成；因“忘记”等排程再次出现时不重复增加完成张数；
- 同一张卡在不同学习日期分别完成时，各日期可各计一次；
- 自由刷题不计入今日目标。

### V25-STUDY-FR-06 首页今日目标卡片

首页使用现有“今日目标”视觉方向，但必须展示真实数据：

- 当前学习项目名称；
- 今日已完成张数 / 每日学习量；
- 当前待复习数量；
- 下一步主按钮：开始学习、继续学习或今日已完成；
- 未选择项目时展示选择或创建学习项目入口；
- 不显示固定 `12/50`、固定百分比、固定连续天数或其他演示值。

## 4. 学习与复习交互

### V25-STUDY-FR-07 统一四档评级

新卡学习和到期复习使用同一基本流程：

1. 展示卡片正面；
2. 用户主动显示背面；
3. 用户根据自己的回忆选择“忘记／困难／良好／简单”；
4. 系统记录评级并由服务端 FSRS 更新后续排程；
5. 进入下一张卡。

评级映射：

| 前端文案 | 排程评级 | 用户理解 |
| --- | --- | --- |
| 忘记 | AGAIN | 没有回忆起来，需要尽快再次学习。 |
| 困难 | HARD | 勉强想起或理解不稳。 |
| 良好 | GOOD | 正常回忆起来。 |
| 简单 | EASY | 非常熟悉，可延长间隔。 |

- 客户端不自行计算下一次到期时间；
- 同一评级重复提交不得增加两次学习记录；
- 网络失败时保留当前卡和用户操作，明确重试，不跳到下一张制造伪成功；
- “忘记”由 FSRS 决定后续再出现时间，前端不另建一套立即重复算法。

### V25-STUDY-FR-08 卡片类型

- `QUESTION` 和 `TRUE_FALSE` 在 V2.5 均用通用 `front/back` 展示；
- 开放深问正面展示开放问题，背面展示“参考思路”；
- 开放深问不得把参考思路包装为唯一标准答案；
- 所有卡片仍由用户自评，系统不自动判断答案对错。

### V25-STUDY-FR-09 排序

- 到期卡优先考虑遗忘风险和逾期程度，风险更高、逾期更久的卡片更早出现；
- 新卡按选定章节顺序和牌组内稳定顺序出现；
- 同一条件下保持稳定排序，避免刷新后顺序无故大幅变化；
- 具体算法参数属于 Architecture，不在 PRD 中固定。

## 5. 自由刷题

### V25-STUDY-FR-10 浏览方式

自由刷题第一版支持：

1. 正序；
2. 随机；
3. 按难度筛选；
4. 只看未掌握；
5. 只看已掌握。

业务规则：

- 自由刷题只浏览卡片，不展示四档评级；
- 不创建复习事件，不改变 FSRS 状态、今日完成数、连续学习天数或统计指标；
- 用户可翻面、前后切换和退出；
- 随机模式在当前一次会话内保持一个顺序，避免返回上一张后立即变化；
- “按难度筛选”指制卡内容难度“基础记忆／理解分析／开放深问／未标注”，不使用或暴露 FSRS 的数值难度；
- 手动新增、文本导入或没有有效制卡难度的卡片归为“未标注”；
- 无符合条件卡片时展示空态，不回退为全部卡片。

## 6. 完成与异常状态

- 今日主计划完成后展示已完成张数和仍待复习积压；
- 有积压时提供“继续复习”，无积压时提供“自由刷题”或返回首页；
- 项目无牌组、牌组为空、没有新卡、没有到期卡应使用不同空态文案；
- 卡片在学习过程中被另一设备删除时，跳过该卡并刷新计划，不让本地队列永久卡住；
- App 被中断后再次进入，应回到今日计划的真实剩余数量，不重复计算已成功提交的评级。

## 7. 验收标准

### V25-STUDY-AC-01 当前项目与范围

- 同一时刻只有一个当前学习项目，选择和切换跨设备一致；
- 新卡只来自选中章节，到期卡仍覆盖当前项目全部已学习卡；
- “未归属章节”中的新卡可以被明确选入计划，不会因缺少真实章节而永久无法学习；
- 独立牌组的到期卡可从牌组详情复习，但不会混入当前学习项目的首页计划；
- 切换或删除项目不错误清除其他项目学习记录。

### V25-STUDY-AC-02 每日计划

- 到期卡优先，剩余额度才由新卡补足；到期数达到目标时不加入新卡；
- 积压超过目标时显示剩余到期数并允许继续；
- 同一张卡当天多次出现只计一次今日完成；
- 多设备在同一账号学习时区下对学习日期和去重结果一致，设备时区变化不会静默重置今日计划；
- 首页今日目标全部使用真实数据。

### V25-STUDY-AC-03 评级与恢复

- 新卡和复习卡均可选择四档评级，服务端排程和学习记录正确更新；
- 重复提交不重复计数；网络失败不越过当前卡；
- 中断并恢复后计划和完成数与服务端一致。

### V25-STUDY-AC-04 自由刷题

- 五种浏览方式均可用；
- 难度筛选使用内容难度四类，不暴露或误用 FSRS 数值难度；
- 浏览过程中不创建评级、不改变排程、今日目标或统计；
- 无匹配卡片展示正确空态。

---

## 8. 模块完成条件

本模块只有在真实项目、真实卡片和真实 FSRS 状态上完成今日计划、评级、恢复和自由刷题验收，
且首页不再展示固定学习数据时，才可标记为 V2.5 学习与复习模块完成。
