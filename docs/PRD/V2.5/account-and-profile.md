# V2.5 模块 PRD：账号与个人主页

| 文档属性 | 内容 |
| --- | --- |
| 所属版本 | v2.5.0 |
| 模块状态 | 已确认 v1.0 |
| 依赖基线 | PRD v2.4 账号、邮箱登录和会话语义 |
| 模块目标 | 保留简单登录，把首页头像和个人资料从 Debug 跳转打磨为真实用户入口 |

---

## 1. 模块边界

本模块负责登录态入口、个人主页弹窗、昵称、预设头像、只读邮箱和退出登录。注册、登录、会话续期、
邮箱规范化和密码规则继续继承 V2.4；V2.5 不新增认证方式。

### 1.1 本期包含

- 首页头像按登录状态执行正确跳转；
- 个人主页使用小型弹窗展示，不新建独立全屏页面；
- 查看并修改昵称；
- 从系统预设头像中选择头像；
- 展示当前登录邮箱，只读；
- 退出当前会话；
- 昵称和头像跨设备保存。

### 1.2 本期不包含

- 修改登录邮箱；
- 上传、拍摄、裁剪或删除自定义头像；
- 找回或修改密码；
- OAuth、手机号、第三方登录和多因素认证；
- 账号注销和跨设备会话管理。

---

## 2. 用户流程

### 2.1 首页头像入口

1. 已登录且会话有效：点击首页头像，打开个人主页弹窗。
2. 本地存在会话但服务端判定失效：关闭业务操作并进入登录页，不展示空白个人主页。
3. 未登录：进入登录页。
4. 重新登录后，首页和个人主页展示账号的真实昵称、头像和邮箱。

### 2.2 个人主页弹窗

弹窗至少展示：

- 当前系统预设头像；
- 昵称；
- 完整登录邮箱，只读；
- “更换头像”；
- “修改昵称”；
- “退出登录”。

点击弹窗外、关闭按钮或系统返回键可关闭弹窗，不丢失已经成功保存的修改。尚未保存的昵称编辑应先退出编辑态，
不得静默覆盖云端资料。

## 3. 功能需求

### V25-ACC-FR-01 昵称

- 昵称沿用 V2.4：1～24 位，可使用中文、字母、数字、`.`、`_`、`-`；允许重名；
- 首尾空白不作为昵称内容保存；空昵称和非法字符需在提交前给出明确提示；
- 保存成功后，弹窗、首页欢迎语和其他昵称展示位置同步更新；
- 保存失败时保留用户输入，允许重试，不显示伪成功；
- 昵称修改不改变登录邮箱、账号身份或历史学习数据。

### V25-ACC-FR-02 系统预设头像

- V2.5 提供 12 个固定系统预设头像，统一采用
  [DiceBear Moods](https://www.dicebear.com/styles/moods/) 风格；
- 预设头像应覆盖不同表情和产品现有蓝、紫、绿、粉、黄等柔和配色，不以性别给头像命名；
- Moods 资源采用 CC0 1.0，可作为内置资源使用；Release 运行时不得依赖 DiceBear 网络接口；
- 头像资源随 APK 打包，用户只选择固定预设项；
- 新用户使用一个固定产品默认头像，随后可随时切换；
- 选择后立即保存；保存失败时恢复原选择并给出重试提示；
- 同一账号在其他设备登录后显示相同头像。

### V25-ACC-FR-03 邮箱展示

- 个人主页展示当前账号的完整邮箱；
- 邮箱为只读信息，不出现编辑、复制替换身份或重新绑定流程；
- 邮箱不得在未登录页面、通知预览或其他账号可见区域泄漏。

### V25-ACC-FR-04 退出登录

- “退出登录”只退出当前设备的当前会话，沿用 V2.4 会话规则；
- 退出后进入登录页，本机不得继续展示受保护的个人、项目、牌组或统计数据；
- 退出不删除云端数据，不中止已经开始的后台制卡任务；
- 用户重新登录后可继续访问原学习项目和任务。

### V25-ACC-FR-05 状态与错误

- 打开弹窗时资料尚未加载完成，应展示稳定加载态；
- 加载失败时展示“重试”，不得使用默认昵称或虚构邮箱冒充真实资料；
- 多设备连续修改时以服务端最后一次成功保存的结果为准，V2.5 不提供冲突合并界面；
- 快速重复点击保存不得产生多个互相覆盖的请求或错误成功提示。

---

## 4. 页面与交互要求

- 弹窗应保持轻量，核心资料在首屏可见；
- 邮箱视觉层级低于昵称，但仍可完整阅读；
- 头像选择使用网格展示 12 个选项，当前项有明确选中标记；
- 头像不得混用当前动漫截图、空白图片或不同画风资源；
- 退出登录使用危险操作样式，但不与“保存资料”放在同一主操作位置；
- Release 不保留“点击头像进入登录页”的旧 Debug 行为。

---

## 5. 验收标准

### V25-ACC-AC-01 入口与资料

- 有效登录态点击首页头像打开个人主页弹窗；无效会话进入登录页；
- 弹窗展示当前真实头像、昵称和完整只读邮箱；
- 不出现空白头像、动漫截图、Mock 用户名或固定邮箱。

### V25-ACC-AC-02 昵称与头像

- 合法昵称保存后在首页和弹窗同步更新，重新启动或更换设备后仍保持；
- 非法昵称不保存并展示明确错误；
- 12 个 Moods 预设头像均可选择，重新登录和跨设备显示一致；
- Release 断网时已打包头像仍能正常显示。

### V25-ACC-AC-03 失败与退出

- 资料读取或保存失败不覆盖旧资料，用户可以重试；
- 退出后受保护页面不可继续访问；重新登录后学习数据仍在；
- 退出不取消后台制卡任务。

---

## 6. 模块完成条件

本模块只在上述验收全部通过、首页头像不再错误跳往登录页、资料来自真实账号且 Release 无旧头像资产引用时，
才可标记为 V2.5 账号与个人主页模块完成。
