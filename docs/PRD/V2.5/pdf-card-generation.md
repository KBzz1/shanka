# V2.5 模块 PRD：PDF 与制卡

| 文档属性 | 内容 |
| --- | --- |
| 所属版本 | v2.5.0 |
| 模块状态 | 已确认 v1.0 |
| 依赖基线 | PRD v2.1 FR-01～FR-13、PRD v2.2～v2.4 的账号归属与恢复语义 |
| 模块目标 | 把一次性 PDF 生成流程升级为可持续、可恢复、可多次制卡的学习项目 |

---

## 1. 模块边界

本模块负责学习项目的创建、PDF 上传与解析、章节确认、制卡配置、样卡、正式生成、失败重试和任务历史。
牌组内编辑与删除由[牌组与卡片管理](deck-card-management.md)负责；生成后的每日使用由
[学习与复习](study-and-review.md)负责。

### 1.1 本期包含

- 以 PDF 为中心的学习项目；
- 上传成功后的全流程自动保存；
- 跨页面、退出 App 和跨设备恢复；
- 同一项目多次制卡；
- 覆盖深度、整数档难度比例、自定义要求；
- 样卡确认与重新生成；
- 后台正式生成和任务状态；
- 完整成功或完整失败；
- 失败任务重试和任务历史删除；
- 项目删除及生成牌组保留选择。

### 1.2 本期不包含

- OCR、扫描版、图片型或没有可用文本层的 PDF；
- 没有可用目录时由 AI 猜测章节或整文兜底；
- 任务暂停；
- 用户可见的生成成本、Token、跳过明细、评分或目标卡片数量；
- 自动修复、自动淘汰、自动补生成和机械重复填充；
- 将生成卡片追加到其他学习项目的牌组。

---

## 2. 核心对象

### 2.1 学习项目

学习项目由以下用户可感知内容组成：

- 一个项目名称；
- 一份或多份学习资料（PDF 或粘贴文本；网页链接预留，本期不包含）；
- 资料产出的章节及用户修订结果；
- 项目内一个或多个牌组；
- 历次制卡任务及其配置、状态和结果；
- 用于后续学习的新卡章节范围。

学习项目是资料集合（V25-D-29）：创建项目与添加资料分为两步，允许先创建仅含名称的空项目，再添加
PDF 或粘贴文本资料；删除项目的最后一份资料后项目保留为空项目。首个资料就绪后项目自动保存。项目
名称默认取首份 PDF 文件名并去掉扩展名（纯文本项目默认取文本标题），允许用户修改；名称为 1～60 个
字符、去除首尾空白、允许重名。项目不是临时向导：即使尚未完成解析、样卡或正式生成，用户也能从学习页
的“制卡任务”区域返回继续。

### 2.2 制卡任务

制卡任务是一次具体生成执行。一个学习项目允许多次制卡，每次任务可：

- 选择项目内各资料的一个或多个章节；
- 使用独立的覆盖深度、难度比例和自定义要求；
- 新建项目内牌组，或追加到本项目已有牌组；
- 在历史中独立显示状态、完成时间和生成卡片数。

项目内生成不得追加到其他项目牌组。脱离项目保留的牌组也不得重新成为其他项目的生成目标。

## 3. 项目与任务状态

PDF 生命周期属于学习项目，制卡执行属于制卡任务，两套状态不得混用。用户侧不展示内部 Worker、批次或
模型状态。

### 3.1 学习项目状态

项目状态由全部资料的解析状态与章节确认状态聚合得出（V25-D-29）：任一 PDF 解析中 → 解析中；
全部解析结束且存在可用章节但尚未确认 → 待确认章节；章节已确认 → 可制卡；全部 PDF 均失败且无
任何可用章节 → 解析失败；项目没有任何资料 → 空项目。

| 状态 | 用户含义 | 可执行操作 |
| --- | --- | --- |
| 空项目 | 尚未添加任何资料 | 添加 PDF、粘贴文本、删除项目 |
| 解析中 | 任一 PDF 资料正在读取文本和目录 | 离开页面、稍后返回、添加文本资料 |
| 解析失败 | 全部 PDF 均无法使用且无可用章节 | 查看原因、更换或追加资料、删除项目 |
| 待确认章节 | 已得到可用章节，等待用户修订或确认 | 编辑章节、确认章节、管理资料、删除项目 |
| 可制卡 | 资料与章节已确认 | 新建制卡任务、管理资料、设置为当前学习项目、删除项目 |

### 3.2 制卡任务状态

| 状态 | 用户含义 | 可执行操作 |
| --- | --- | --- |
| 草稿 | 正在选择章节、牌组和生成配置 | 继续配置、放弃任务 |
| 样卡生成中 | 正在生成本次样卡 | 离开页面、稍后返回 |
| 待确认样卡 | 已生成样卡，等待决定 | 正式生成、改配置后重生成样卡、放弃任务 |
| 生成中 | 正在正式生成 | 离开页面、稍后返回 |
| 已完成 | 至少 1 张卡片已完整发布 | 查看牌组、再次制卡、删除任务历史 |
| 失败 | 本次任务整体失败 | 重新生成、查看简明错误、删除任务历史 |
| 已放弃 | 用户在正式生成前主动结束本次任务 | 查看历史、删除任务历史 |

“放弃本次制卡”把任务转为“已放弃”并保留历史，不删除学习项目、PDF、章节或其他任务。V2.5 不提供
“暂停”和“继续暂停任务”；正式生成开始后也不提供取消。退出 App 或切换设备不视为暂停。

## 4. 功能需求

### V25-GEN-FR-01 自动保存与恢复

- 项目创建（仅名称）即自动保存；添加资料成功是解析与制卡的起点；
- 项目默认名称、用户修改后的名称和修改时间跨设备保存；
- 已添加资料、解析状态、章节修订、当前步骤、任务配置和任务状态均保存到账号；
- 用户退出 App、切换页面、网络短暂中断或更换设备后，不需要重新添加资料；
- 学习页新增“制卡任务”区域，展示未完成、失败和近期完成任务，并提供继续入口；
- 恢复后以服务端最新状态为准，不重复启动已开始的生成，也不重复写入卡片；
- 解析失败时保留项目，并允许用户更换或追加资料后重新解析。

### V25-GEN-FR-02 资料与章节

- 学习项目可包含多份资料：PDF 文件与粘贴文本；网页链接为预留类型，本期不提供；
- PDF 资料：继续支持具有可提取文本层和可识别目录结构的 PDF；≤100MB、≤1000 页；
- 粘贴文本资料（V25-D-32）：作为一个章节（章节名默认取文本标题，可修改），服务端按段落切分为
  多个文本块，每块数千字，禁止整块单块；单份文本上限 30000 字；文本资料添加成功即就绪，无需解析；
- 项目状态按资料聚合（见 3.1）；任一 PDF 解析中不影响已就绪资料的章节展示；
- 用户可修订章节名称、起始页、结束页（文本章节无页码），并跨全部可用资料选择一个或多个章节；
- 新增或删除任一资料都会重置项目章节确认状态（V25-D-31）：需重新确认章节后方可再次制卡；
- 解析失败时展示明确原因和可用操作，不删除原文件；仅解析失败的 PDF 资料支持原位替换并重新解析；
- 项目建立后不再提供独立、无上下文的“删除 PDF”操作；资料删除入口为资料管理中的“删除资料”；
- 资料删除（V25-D-30）必须二次确认：从该资料生成的卡片由用户选择“保留”或“一并删除”，确认页
  展示将影响的卡片数量；资料被活跃任务引用时，确认后由服务端静默取消这些任务并使迟到写入失效；
- 删除项目的最后一份资料后项目保留为空项目；
- 被草稿、样卡生成中、待确认样卡或生成中任务引用的章节不得删除；界面列出阻塞任务，用户可先放弃
  尚未正式生成的任务，生成中任务则需等待完成或失败；
- 删除一个无阻塞任务引用的章节前必须确认，并明确说明其将退出后续制卡和新卡范围；已生成卡片默认保留，
  只有用户明确选择“同时删除该章节生成的卡片”时才删除；保留的卡片进入“未归属章节”。

### V25-GEN-FR-03 覆盖深度

面向用户保留三档，但不显示数量、区间或预计卡片数：

| 档位 | 产品语义 |
| --- | --- |
| 精简 | 覆盖章节的核心概念、关键定义和最重要结论。 |
| 均衡 | 在核心知识之外，覆盖重要关系、原因、对比和支撑知识。 |
| 充分覆盖 | 尽可能覆盖所有具有独立学习价值的知识点，包括低频细节；知识较少时允许围绕同一知识点形成不同学习角度，但不得产生同义重复卡。 |

Planner 负责识别哪些知识值得覆盖；代码仍负责隐藏的调用上限、成本边界、状态机、唯一标识和安全硬限制。
覆盖深度不是固定数量承诺，用户界面和提示词均不得要求模型“凑够 N 张”。

数量采用目标密度制（V25-D-26）：服务端按章节内容规模（每 1 万字 ≈ 精简 6 张 / 均衡 12 张 /
充分 20 张）推导目标区间下发给 Planner；Planner 在区间内按实际内容取舍——来源充分时向区间
上部规划，来源稀薄时允许低于区间下限输出，薄内容不注水、富内容不偷工。区间上限与任务级单元
硬上限仍是代码执行的护栏；向用户界面仍不展示数量、区间或预计卡片数。

### V25-GEN-FR-04 难度比例

- 使用现有“三段比例条 + 两个拖动点”交互；
- 两个拖动点均按 10% 步长移动，只允许 0、10、20……100；
- 基础记忆比例 = 第一个拖动点位置；
- 理解分析比例 = 第二个拖动点位置 - 第一个拖动点位置；
- 开放深问比例 = 100% - 第二个拖动点位置；
- 三档之和始终为 100%，任一档允许为 0%；
- 拖动一个点时只影响与该点相邻的两段，不出现负数、小数或总和不为 100%；
- 默认值跨设备保存，由[设置模块](settings.md)管理。

难度语义：

| 难度 | 定义 |
| --- | --- |
| 基础记忆 | 直接回忆事实、术语、定义和明确结论。 |
| 理解分析 | 解释关系、原因、差异、条件或推理过程。 |
| 开放深问 | 面向场景、迁移、权衡或多知识点综合的开放问题；答案侧提供参考思路，不声称唯一标准答案。 |

开放深问只生成普通问答卡（`QUESTION`），不生成判断题；判断题（`TRUE_FALSE`）只可用于基础记忆或
理解分析，并继续以通用 `front/back` 展示。

### V25-GEN-FR-05 样卡

- 样卡只展示当前难度比例大于 0 的档位，每个启用档位 1 张，因此共 1～3 张；
- 若某档比例为 0%，样卡中不显示该档，也不使用占位卡；
- V2.5 以“每个启用难度 1 张”替换 V2.1 的“固定 3 张、2 张问答 + 1 张判断”构成；
- 样卡不再承诺固定问答卡/判断题数量，但开放深问样卡必须是普通问答卡；
- 样卡必须基于已选 PDF 内容，不使用与原文无关的虚构示例；
- 样卡继续使用通用 `front/back` 展示；
- 样卡不写入牌组、不进入学习与统计，也不允许直接编辑；
- 用户可选择：确认并正式生成；修改配置后重新生成样卡；放弃本次制卡；
- 修改生成配置后，原样卡失效，必须重新生成并确认；
- 样卡界面不展示预计总卡数、费用、Token 或模型内部信息。

### V25-GEN-FR-06 正式生成

- 正式生成只有完整成功和整体失败两种用户结果；
- 生成期间卡片可以在内部暂存，但在任务成功前不得出现在牌组、学习、搜索或统计中；
- 全部必要处理成功且至少生成 1 张卡片后，一次性发布整批卡片，并展示“已完成，共生成 N 张”；
- 0 张卡片不得记为已完成，应进入失败状态并允许用户调整章节或配置后新建任务；
- 不展示跳过数量、部分完成比例、成本或内部重试次数；
- 任务失败时，整批结果隔离且不可见，不显示“已生成的部分”；
- 正式生成开始后不提供暂停或取消按钮；用户可以安全离开页面；
- 判断题继续采用通用 `front/back` 展示，不要求 V2.5 增加专用判断题组件。

### V25-GEN-FR-07 失败与重新生成

- 失败页面提供“重新生成”主按钮；
- 点击重新生成会创建一条关联原失败任务的新任务，原任务继续以“失败”保留在历史中；
- 新任务沿用原章节资料、目标牌组、配置和已确认样卡，不要求用户重新选择；正式生成阶段失败时，
  新任务可直接重新开始正式生成；样卡生成阶段失败时，新任务重新生成样卡；
- 新任务成功后一次性显示完整结果；原任务隔离的失败结果不得重复出现；
- 用户若修改章节、覆盖深度、难度比例、自定义要求或目标牌组，应创建新的制卡任务并重新走样卡确认；
- 失败错误面向用户说明下一步，例如检查 API Key、网络后重试或更换 PDF，不展示内部异常栈。

### V25-GEN-FR-08 任务历史

- 制卡任务在用户删除任务或删除学习项目前持续保留在项目历史中；
- 重试产生的新任务展示“重试自：原任务”，原失败任务展示“已创建重试任务”，两者可相互查看；
- 删除任务前展示该任务状态和生成卡片数量；
- 默认只删除任务历史，保留牌组与卡片；
- 用户可勾选“同时删除该任务生成的卡片”；勾选后必须明确展示将删除的卡片数量及相关学习记录；
- 删除任务生成的全部卡片后，空牌组仍保留，除非用户另行删除牌组；
- 草稿、样卡生成中或待确认样卡任务需先放弃再删除；生成中任务必须等待其进入完成或失败状态。

### V25-GEN-FR-09 删除学习项目

- 删除学习项目前必须二次确认；
- 项目处于解析中或存在活跃制卡任务时，确认删除后由服务端自动取消关联任务；界面不暴露任务处理选项；
- 解析租约和任务 worker 的 fencing 必须使迟到结果无法重新写回已删除项目；
- 系统询问是否保留已经生成的牌组及卡片；
- 无论是否保留牌组，项目的全部资料、章节、制卡任务历史和项目配置均删除；
- 选择保留时，项目内牌组及其中全部生成、手动和导入卡片一并脱离项目继续存在并可学习，但依赖原 PDF
  的来源查看和 AI 重写能力不可再承诺；
- 选择不保留时，项目内牌组及其中全部生成、手动和导入卡片与相关学习记录一并删除；确认页分别展示
  三类卡片数量；
- 删除完成后若该项目是当前学习项目，应回到“未选择当前项目”状态，由用户重新选择。

### V25-GEN-FR-10 AI 制卡质量验收

AI 质量是 Release 验收要求，但不在运行时引入自动修复、自动淘汰或固定数量补齐：

- 每张样卡和正式卡都能追溯到本次所选 PDF 的实际来源内容；
- 卡片不得包含与来源矛盾、来源未支持的事实结论或模型虚构的专有信息；
- 同一任务不得出现正反面仅作轻微改写的同义重复卡；
- 精简应聚焦核心知识，均衡应增加重要支撑关系，充分覆盖应进一步覆盖独立有价值的低频知识；
- 开放深问必须能由来源知识和合理推理支撑，背面明确使用“参考思路”，不伪装成唯一答案；
- 判断题的正误与解释必须一致；
- 样卡展示的语言风格、长度和难度应能代表正式卡片，不能用样卡掩盖正式生成质量。

Release 验收使用固定 PDF 夹具，对同一代表性章节分别执行精简、均衡和充分覆盖任务，并人工审查全部产出。
出现来源外事实、事实矛盾、正反面冲突或同义重复时不得判定 AI 质量通过；不同覆盖档位不以卡片数量单调
作为通过条件。

## 5. 页面与交互要求

- 未完成任务在学习页集中展示，不要求用户回忆上次停留页面；
- 状态文案只使用用户能理解的业务阶段，不暴露 `PLANNING`、批次、游标或模型调用名；
- 任何超过即时反馈的操作先进入加载或后台状态，按钮不可重复触发；
- 网络失败不清空已填写配置；
- 完成页主操作为“查看牌组”，次操作为“再次制卡”；
- 失败页主操作为“重新生成”，不把“删除任务”放在更突出位置；
- 项目和任务列表清楚区分项目状态与任务状态，并展示项目名称；
- Release 不出现暂停按钮、成本估算、固定数量提示或无法工作的入口。

## 6. 验收标准

### V25-GEN-AC-01 项目保存与恢复

- PDF 上传成功后退出 App，再次进入可从正确步骤继续；
- 在另一台设备登录同一账号可看到项目、章节修订、配置和任务最新状态；
- 恢复不会重复上传、重复启动任务或重复写入卡片。
- 项目默认名称来自 PDF 文件名，修改后跨设备一致且允许与其他项目重名。

### V25-GEN-AC-02 配置与样卡

- 三档覆盖深度不展示数量，并体现约定语义；
- 难度滑块只能形成 10% 整数档、允许 0%、始终合计 100%；
- 样卡只按非零难度生成 1～3 张，并可确认、改配置重生成或放弃；
- 样卡不进入正式牌组或统计。

### V25-GEN-AC-03 完整成功与失败

- 成功任务只展示“已完成，共生成 N 张”，全部卡片一次性进入目标牌组；
- 失败任务不在牌组、学习或统计中暴露部分卡片；
- 点击重新生成不需要重新上传 PDF 或重选原配置，成功后不产生重复卡片；
- 原失败任务仍保留，新任务与原任务关联；0 张卡片不会显示为完成；
- 生成期间离开页面或退出 App，任务仍继续且可在学习页查看。

### V25-GEN-AC-04 多次制卡与删除

- 同一项目可多次制卡，新建或追加到本项目牌组；不能追加到其他项目牌组；
- 删除任务默认保留卡片，可选择连卡片和相关学习记录一起删除；
- 删除项目时能正确执行“保留牌组”或“连牌组删除”两种结果；
- 所有高影响删除都展示影响范围并要求确认。

### V25-GEN-AC-05 状态与质量

- 项目状态与任务状态分开展示；放弃样卡任务后进入“已放弃”终态；
- 活动任务正确阻止项目、引用章节和目标牌组删除；
- 固定 PDF 夹具的三档覆盖任务满足 V25-GEN-FR-10，且验收不以固定卡片数量为标准。

### V25-GEN-AC-06 资料集合与资料管理

- 先建空项目再添加 PDF 与粘贴文本资料均可行；空项目只提供添加资料与删除项目；
- 添加粘贴文本资料后立即出现一个可修改名称的章节，且无需解析；
- 任一 PDF 解析中项目呈现解析中，文本资料不受影响；
- 新增或删除资料后项目回到待确认章节，确认后才能再次制卡；
- 删除资料时可选“保留卡片”或“一并删除”，被活跃任务引用时服务端静默取消任务；
- 删除项目的最后一份资料后项目保留为空项目；
- 单份粘贴文本超过 30000 字时被拒绝并明确提示。

## 7. 模块完成条件

本模块只有在真实 PDF、真实账号、真实持久化和真实后台任务上通过上述验收，且不存在暂停、Mock 完成、
部分结果泄漏或重新上传要求时，才可标记为 V2.5 PDF 与制卡模块完成。
