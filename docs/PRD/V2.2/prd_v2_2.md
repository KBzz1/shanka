## 1. 产品概述（V2.2 增量）

### 1.1 产品目标（V2.2 增量）

在 v2.1 目标 6「让牌组、卡片和复习结果有可持久化、可同步的服务端数据来源」基础上：以**账号体系**
确立服务端数据主体。用户注册/登录后，其全部业务数据（牌组、卡片、PDF、任务、复习、API Key、LLM
调用账本）按账号（`user_id`）归属与隔离；同一账号可在多台设备上分别登录访问自己的数据。账号一期
不含旧匿名数据认领与跨设备数据合并界面（见 §3.2）。

### 1.2 产品原则（V2.2 增量）

- 账号体系取**最简形态**：用户名 + 密码，opaque Bearer session，无邮箱、无第三方登录、无 refresh token。
- 安全基线优先：密码 Argon2id 哈希、token 只存摘要、统一 401/404 不暴露存在性。
- 认证方式替换为**一次性切换**（决策 D-05）：X-Device-ID 退出普通运行时认证/授权/幂等/限流，不做双认证长期保留。

## 2. 账号用户流程（V2.2 新增）

### 2.1 注册与登录

1. 用户打开 App，未持有有效会话时进入登录页（登录/注册切换）。
2. 注册：输入用户名与密码 → `POST /auth/register` → 服务端创建用户并直接建立会话 → 返回用户资料、
   token 与有效期 → 进入主应用。用户名已被占用 → `409 USERNAME_TAKEN`，提示更换用户名。
3. 登录：输入用户名与密码 → `POST /auth/login` → 校验通过建立新会话（不撤销该用户其他设备的会话）
   → 进入主应用。用户名不存在与密码错误**统一** `401 INVALID_CREDENTIALS`，不暴露账号存在性。
4. App 启动时持本地 token 调 `GET /auth/me` 验证会话；有效则进入主应用，无效则回登录页。

### 2.2 会话与退出

- 会话默认 30 天绝对有效期，无滑动续期、无 refresh token；到期后需重新登录。
- 退出：`POST /auth/logout` 只撤销**当前**会话（其他设备的会话不受影响），返回 204。
- 受保护请求携带 `Authorization: Bearer <token>`；缺失/非法/撤销/过期 token 一律 `401 AUTH_REQUIRED` /
  `AUTH_INVALID` 并带 `WWW-Authenticate: Bearer` 响应头。
- 会话过期或撤销不影响已创建的任务：任务按 `user_id` 归属后台继续执行，用户重新登录后可查看与继续。

### 2.3 未登录体验

未登录状态下除注册/登录接口外，所有业务接口均拒绝访问（401）。不提供游客模式或匿名使用路径。

## 3. 产品范围调整

### 3.1 本期范围（V2.2 新增项）

- 用户名/密码注册与登录；
- opaque Bearer session 管理（签发、校验、撤销当前会话、`/auth/me`）；
- 全部业务、幂等、统计、API Key 与 LLM 后台链路按 `user_id` 归属与隔离；
- Android 客户端登录态（安全存储 token、401 自动回登录页）；
- test-platform 账号化联调能力。

### 3.2 本期不包含（V2.2 新增项）

- 邮箱、手机号等非用户名标识；找回密码、账号注销；
- OAuth/第三方登录、多因素认证；
- JWT、refresh token、滑动续期；
- **旧 device_id 数据认领/迁移**（决策 D-06）：v2.1 匿名设备数据原样保留、不迁移、不删除、无访问
  路径；清理属后续独立发布；
- 跨设备数据冲突处理界面与手动同步入口（v2.1 §3.2 原排除项维持；账号体系为后续云端同步预留基础，
  但本期不做任何合并/冲突 UI）；
- 周目标云端同步（v2.1 §5.17 备注的扩展能力本期不实施，周目标维持客户端本地保存）。

## 4. 功能需求（V2.2 新增）

### 4.1 FR-19 账号与会话

#### 凭据

- 用户名：3~32 位，仅允许 ASCII 小写字母、数字、`.`、`_`、`-`；服务端统一转小写后校验与唯一化。
- 密码：8~128 个字符，允许空格与任意字符，不设大小写/数字组合规则；**禁止静默截断**，不做 Unicode
  normalization 或大小写转换。
- 密码存储：Argon2id；生产参数不得低于 `memory_cost=19456 KiB, time_cost=2, parallelism=1`。测试可注入
  低成本 hasher，但生产默认与配置守卫不得被测试参数降低。
- 登录失败统一 `401 INVALID_CREDENTIALS`；用户名不存在时仍执行一次固定 dummy Argon2id 校验，降低
  账号存在性时序差。
- 注册用户名冲突返回 `409 USERNAME_TAKEN`；响应与日志均不得包含密码或 password hash。

#### 会话

- 256-bit 随机 opaque bearer token（如 `secrets.token_urlsafe(32)`）；不使用 JWT。
- 数据库只保存 token 的 SHA-256 摘要；明文 token 只出现在注册/登录成功响应与客户端安全存储中。
- 默认 30 天绝对有效期；logout 只撤销当前会话；同一用户允许多个独立会话。
- 受保护请求缺失/非法/撤销/过期 token → `401 AUTH_REQUIRED` / `AUTH_INVALID` + `WWW-Authenticate: Bearer`。

#### 接口与响应形状

| 接口 | 鉴权 | 语义 |
| --- | --- | --- |
| `POST /auth/register` | 否 | 创建用户与会话；201 返回 user、token、expires_at |
| `POST /auth/login` | 否 | 校验凭据；200 返回 user、token、expires_at |
| `POST /auth/logout` | Bearer | 撤销当前会话；204 |
| `GET /auth/me` | Bearer | 返回当前用户最小资料（`user`） |

- register/login 请求体仅含 `username`、`password`；成功响应含 `user {user_id, username, created_at}`、
  `access_token`、`token_type="Bearer"`、`expires_at`。
- 客户端（含测试 client）不得自动重试 register/login，避免网络重放静默创建多条会话。
- 探针（/healthz、/readyz）、/metrics、/openapi.json 与 register/login 豁免 Bearer；其余业务接口全部
  需要 Bearer。X-Device-ID 从 OpenAPI、Android 普通请求与测试平台普通请求中删除。

#### 数据归属与隔离

- 所有业务资源按 `user_id` 归属与隔离；资源跨用户访问统一返回 404，不暴露存在性。
- 幂等去重域：`(user_id, 接口路径含具体资源 ID, idempotency_key)`；复习事件 `client_event_id` 用户内唯一。
- 限流：register/login 至少按来源 IP 限流，login 额外按规范化用户名分桶；认证完成后的业务限流键为
  `user_id`，同时保留 IP 总闸门。
- LLM 后台链路：`tasks.user_id` 为后台执行身份锚点；后台执行不持有 bearer token；`llm_call_attempts.user_id`
  为账本归属与成本聚合键；logout/session 过期不取消已创建任务。
- 敏感信息：`Authorization`、密码、token、password hash、API Key、完整 Prompt 与模型原文不得进入
  日志、错误响应、测试报告或命令参数；日志身份字段为 `user_id`。

## 6. MVP 验收标准（V2.2 新增）

### AC-12：账号与会话

- 注册成功后返回 `user`、`access_token`、`token_type="Bearer"`、`expires_at`；重复用户名返回
  `409 USERNAME_TAKEN`。
- 登录失败（用户名不存在或密码错误）统一返回 `401 INVALID_CREDENTIALS`，响应与日志不含密码/hash。
- 缺失、非法、撤销或过期 token 一律 `401` 且带 `WWW-Authenticate: Bearer`。
- logout 只撤销当前会话（204）；同一用户其他会话不受影响。
- 跨用户资源访问一律 404（牌组/卡片/PDF/任务/API Key/LLM 账本），不暴露存在性。
- 幂等键与 `client_event_id` 在不同用户间可复用（用户域隔离）。
- 会话过期/退出后已创建任务继续按 `user_id` 执行，重新登录后可查看与继续。
- 密码、token、password hash、Authorization 头不进入日志、错误响应、测试报告或命令参数。

## 7. 风险与边界提示（V2.2 新增）

- **session token 等同于密码**：泄漏后在被撤销或 30 天过期前可被冒用；token 只存摘要、只走 HTTPS。
- logout 只撤销当前会话；用户在其他设备的会话独立，无法跨设备一键下线。
- 本期无找回密码与账号注销：丢失密码后无法自助恢复该账号数据访问。
- 旧 device_id 数据（v2.1 匿名期数据）不可访问、不可认领（决策 D-06）；用户需以新账号重新开始。
