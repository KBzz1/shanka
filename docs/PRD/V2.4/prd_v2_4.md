## 1. 产品概述（V2.4 增量）

### 1.1 产品目标（V2.4 增量）

在 v2.2/v2.3 账号体系与设备架构彻底清除的基础上：登录键切换为邮箱（email+password），
username 降为主界面展示名（昵称化，可重名）；会话引入活跃滑动续期实现长期登录
（活跃用户永不过期，连续 30 天不活跃才过期，登出即时失效）；登录/注册屏补齐全量错误
提示 UX（中文文案 + 3 秒倒计时整体消失）；平台 bootstrap 增加 429 重试与按 3 规划组的
预算推导，提升登录/注册体验与联调稳定性。

## 2. 变更详情

1. **账号登录键切换**：login 用 email+password；register 收 username+email+password
   （三字段）。
2. **username 降为展示名**：1-24 位中文/字母/数字/._-，可重名（去 UNIQUE），不再强制
   小写；主界面展示用，不参与登录。
3. **users 表加 email 列**：NOT NULL + UNIQUE，存 lowercase 规范化值；迁移
   （revision `ad7849aad10e`）清空存量账号及下游数据（决策记录：开发期数据清空重来）；
   downgrade 显式拒绝。
4. **错误码**：EMAIL_TAKEN(409) 新增（取代注册冲突旧码）；INVALID_CREDENTIALS 文案
   「邮箱或密码错误」。
5. **长期登录**：会话滑动续期——活跃续期至 now+30 天，按天节流；连续 30 天不活跃
   过期；登出即时失效。
6. **前端错误提示 UX**：全量错误码→中文文案映射 + 3 秒倒计时（右侧纯数字【3】【2】【1】）
   归零整体消失；仅登录/注册屏。
7. **忘记密码提示**：文案「请手动联系开发者直接修改密码。」；注册确认密码本地校验；
   密码提示「至少 8 位」。
8. **平台**：bootstrap 429 按 Retry-After 重试 ≤3 次；PLANNING 预算按 3 规划组推导。
9. **排除项**：登录屏「直接进入」按钮维持现状（用户裁决不动）。
