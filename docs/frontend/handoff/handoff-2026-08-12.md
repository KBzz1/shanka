## 2. 样卡预览（2026-08-12 排查结论）

**后端结论：`POST /samples` 接口正常、无故障，前端页面空白需按 §2.1 对照。**

证据链：

- 前端发起的 `POST /samples`（16:00:57Z）后端返回 200，响应含 3 张样卡，`card_id` / `front` / `back` / `card_type` 均有值；本机复现同一请求结果一致。
- 实际响应与 openapi.yaml `SampleCard` 定义完全一致：`required` 仅 4 字段，其余字段可空。
- 该请求之后后端未再收到任何请求（无重试、无 `POST /tasks`）——请求已到达且已返回，卡点在客户端本地。

### 2.1 前端需确认：样卡渲染字段（页面空白的最大嫌疑）

`SampleCard` 字段语义（structure-contract 3.13）：

- `front` / `back`：**通用渲染字段，所有卡片保证有值**；
- `question` / `answer`：标注「仅 QUESTION 卡」，但当前实现恒为 `null`（尚未填充）；
- `statement` / `answer_boolean` / `explanation`：仅 TRUE_FALSE 卡有值。

若样卡 UI 渲染 QUESTION 卡的 `question` / `answer` 字段，会拿到 `null` → 页面空白且无报错。**请确认渲染字段用 `front` / `back`。**

### 2.2 前端需注意：API Key 校验语义（样卡通过后同样会卡）

`POST /tasks`（样卡确认后创建生成任务）要求设备已保存有效 API Key：

- `PUT /api-key` 对无效 Key（`status=INVALID` / `INSUFFICIENT_BALANCE`）**返回 200 但不落库**；
- 判断保存成功以 `GET /api-key/status` 返回 `status=AVAILABLE` 为准，不要只看 PUT 的状态码。

### 2.3 自查方法

后端所有响应带 `X-Request-ID` 响应头；报障时记录该头，后端可直接对照日志。

### 3.1 上传链路（已通）

| 15:59:41Z / 15:59:52Z | 文字版 PDF（11.5MB）上传 → **201**，随后解析成功 **PARSED**（12 章节） |

此前两次失败（21:43 的 502、23:11 的 ConnectionReset）根因已定位并修复：

- 21:43：WSL2 上 cloudflared QUIC 隧道断连（已切 **http2 协议**根治）；
- 23:11：文件 72.9MB 超旧 50MB 上限 → 后端 400（响应回程断连）。**上限已放宽 100MB / 1000 页**（与 Cloudflare 免费版 100MB 对齐）。

### 3.2 扫描版 PDF：解析失败为产品边界

72.9MiB 文件解析结果为 `FAILED / PDF_PARSE_FAILED`：313 页、有完整目录，但**前 5 页文本提取为 0 字符 → 无文本层（扫描版/图片型 PDF）**。

`PDF_PARSE_FAILED` 是**契约设计行为**：PRD 5.2 明确文本层失败终止流程、**无 OCR/AI 兜底**。前端按 `error_code` 展示「解析失败/无文本层」并终止流程即为正确行为，**不是联调缺陷**。

**产品边界**：当前 MVP 不支持扫描版 PDF（需要文字版/带文本层的电子版）。如需扫描版支持（OCR），属后续迭代需求（可录入 backlog）。

### 3.3 诊断能力（已增强）

- 解析失败会记后端日志：`main/data/logs/app.log`，`level=WARN`，含 `error_code` / `error_message` / `file_id` / `device_id`（`message` 保留给日志正文，不重复承载错误文本）。
- 上传请求日志含 `size_bytes` / `content_type` / `file_name`（脱敏，不记内容）。
- 前端报障请记录响应头 `X-Request-ID`（后端所有响应都带，替代本地 8 位 trace，可直接对照服务端日志）。

## 5. 契约确认

- **Task PAUSED**：契约 4.1 已修订为「预留状态」——PRD 5.12 仅定义任务恢复（resume），无暂停接口需求；前端「暂停生成」按钮保持本地状态，不改变服务端 RUNNING。
- **导入语义**：原子回滚（任一失败 → 422 整体失败），逐条结果仅全成功时返回；`FAILED` 枚举为预留形态。
- **错误码全集**：含 `CHAPTER_NOT_FOUND`（404，localization_key=`error.chapter_not_found`），完整清单以线上 `/openapi.json` 为准。
- **看板字段**：`weekly_total` / `mastered_card_count` / `recall_accuracy` 等已在 OpenAPI 固定，比例 0–1，分母为 0 返回 `null`。

## 7. 价格预估接口对接说明（2026-08-12 新增）

- **用途**：创建任务前向用户展示预计花费（用户自持 Key，成本敏感）。
- **语义**：纯计算、不落库、不消耗 Key/余额、豁免幂等键（`/samples` 先例）；`chapter_ids` 只做计数（归属校验在创建任务时）。
- **区间含义**：`price_low` = 全部 prompt 命中缓存（乐观下限），`price_high` = 全部未命中（保守上限），真实成本落在区间内；`output` 按固定价。
- **估算依据**：知识点数 = 章节数 × 3 × 密度系数（COMPACT=1/BALANCED=2/EXTENSIVE=3），每知识点一卡；单价常量在后端 `cost.py`（前端不硬编码价格）。
- **错误**：`chapter_ids` 为空或 `generation_config` 非法 → 400 VALIDATION_ERROR（与创建任务同口径）。
