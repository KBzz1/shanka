# 规划质量实验 Rubric（草稿，仅用于消融实验人工核验）

对"主题清单 + 生成单元清单"整体评分，每维整数 0~3。评委只依据章节原文与清单本身，
不使用外部知识。长度与措辞本身不加分。

## 1. 覆盖充分度（coverage）

抽查章节各小节，实质知识点是否都有主题对应。

| 分数 | 锚点 |
| --- | --- |
| 0 | 大量小节（>1/3）的实质知识点无任何主题对应。 |
| 1 | 主要小节有覆盖，但明显遗漏多处实质知识点。 |
| 2 | 覆盖基本完整，仅个别次要点遗漏；档位语义（COMPACT 只留核心 / EXTENSIVE 含低频）基本成立。 |
| 3 | 覆盖完整且档位语义准确：COMPACT 恰好只剩核心，EXTENSIVE 连低频细节都有对应。 |

## 2. 主题原子性（atomicity）

| 分数 | 锚点 |
| --- | --- |
| 0 | 多数主题是复合知识块（"N 要素及各自职责"式）。 |
| 1 | 存在若干复合主题或粒度严重不均。 |
| 2 | 绝大多数主题原子；个别边界情况可辩。 |
| 3 | 全部主题单一、可独立出卡；枚举型知识按"集合/成员"正确拆分。 |

## 3. 层级准确性（tier）

| 分数 | 锚点 |
| --- | --- |
| 0 | 层级标注大面积错误（核心标低频、反之亦然）。 |
| 1 | 多处层级与定义不符。 |
| 2 | 个别主题层级可辩，整体符合 CORE/IMPORTANT/LOW_FREQUENCY 定义。 |
| 3 | 层级全部准确，且档位过滤语义正确（COMPACT 内无 IMPORTANT/LOW_FREQUENCY）。 |

## 4. 单元质量（units）

针对生成单元清单（学习目标/难度/卡型）：

| 分数 | 锚点 |
| --- | --- |
| 0 | 目标大面积不可检验、复合或难度错标；同主题同认知动作重复。 |
| 1 | 存在明显的复合目标、难度错档或重复单元。 |
| 2 | 目标基本单一可检验，难度锚定大体准确，重复极少。 |
| 3 | 全部目标单一、具体、可检验；难度真实（BASIC=回忆原子、UNDERSTANDING=组织关系、DEEP=新场景应用）；同一主题多角度但不同义重复。 |
