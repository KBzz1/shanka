# 问答直通模式（QA_DIRECT）盲评 rubric v1

制定：2026-09-25（V25-D-43 问答直通制卡模式验收）。**与 EXTRACT 模式生产 rubric v3
（evidence / correctness / difficulty / learning_value）不通用**：本模式的产品承诺是
"资料已形成问答，AI 不命题、不改答案、仅做格式与卡面字段适配"（用户裁决：仅格式规范化），
因此评分维度围绕**忠实度**设计，而非命题质量。rubric 演进规则同生产资产：修订 = 新版本 +
CHANGELOG 留痕，已发布版本禁原地改。

## 裁判须知

- 你拿到：题库原文（唯一事实源）+ 待评卡片列表。逐卡独立评分。
- 盲评：你不知道、也不应猜测生产评分器的分数；只按本 rubric 打分。
- 每维 0-3 整数；只依据可见材料判断，**不做外部知识纠错**（题库即事实源，即使题库内容
  与你的知识冲突，也以题库为准）。
- 逐维独立打分，禁止总分补偿。

## Q1 题干保真（front 是否忠于原题）

判断题卡的口径同此：评的是陈述句是否忠于原陈述。

| 分 | 标准 |
| --- | --- |
| 3 | 与题库中某问答对的原题干逐字一致，或仅排版级清理（剥题号、去多余空白、统一标点/全半角） |
| 2 | 措辞微小调整（同义替换、补全省略主语），提问对象与意图不变，原答案仍可原样作答 |
| 1 | 明显改写：换问法、合并多题、拆分一题、提问对象漂移（原答案不再严格对应） |
| 0 | 题库中找不到对应问答对（自创题） |

## Q2 答案保真（back 是否照录原答案）

问答题的答案 = back 正文；判断题的答案 = answer_boolean（与原判断一致）+ explanation
（承接原解析、不引入新结论）。

| 分 | 标准 |
| --- | --- |
| 3 | 事实集与原答案一致，仅排版重排（分段、列表化、代码块化、剥题库排版噪声） |
| 2 | 措辞微调但事实集不变（无增、无删、无语义位移） |
| 1 | 增删要点、改变数值/结论、或"纠正/优化"了原答案的实质内容 |
| 0 | 与对应原答案不符、判断题布尔与原判断相反，或答案为自造 |

## Q3 自包含可复习（卡面独立可用）

| 分 | 标准 |
| --- | --- |
| 3 | 问答独立成卡：无"见上文/如下图/如前所述"式悬空指代，代词有明确指称，答案完整不截断 |
| 2 | 轻微上下文依赖（如省略主语），但不影响作答与核对 |
| 1 | 需要回到题库上下文才能理解题干或核对答案 |
| 0 | 答案残缺、指代悬空，卡片无法使用 |

## Q4 卡面字段适配（格式规范化质量）

| 分 | 标准 |
| --- | --- |
| 3 | 字段分派正确（题干→front、答案→back、补充说明→explanation、代码进代码块），markdown 干净无残留题号/原始格式噪声；判断题形态正确：陈述句作 front、判断走 answer_boolean 字段、解析走 explanation |
| 2 | 轻微噪声（残留编号、多余空行、标点不统一），不影响使用 |
| 1 | 字段错位（如答案主体进 explanation）、判断题形态错位（如把布尔结论写成文字塞进 back、解析丢失），内容尚可读 |
| 0 | 格式混乱破坏可读性（代码未进代码块导致串行、markdown 结构坍塌等） |

## 判分纪律

- Q1=0 当且仅当该卡在题库中找不到对应问答对；此时 Q2 以"卡面答案是否在任何意义上
  对应题库知识"为 0-1 记分，notes 必须写明"自创"。
- notes 每卡 ≤20 字，只记定分依据（例："剥题号正确" / "答案新增了原文没有的要点"）。
